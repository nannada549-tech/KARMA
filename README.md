# ARCHIVE — 캐릭터 프롬프트 보관함

파일 구성

- `index.html` 뼈대
- `style.css` 디자인 (색은 맨 위 `:root`에서 바꿔요)
- `app.js` 동작 (건드릴 일 없음)
- `data.js` **내용 전부** — 캐릭터, 소개, 프롬프트, 입장 대사
- `images/` 사진 폴더

## 화면 구성

1. 입장 화면: 영화 같은 검은 띠 + 사진 + 대사
2. 첫 화면: 캐릭터가 세로로 나열
3. 캐릭터를 누르면 상태창: 옆에 사진, 소개, `프롬프트 복사` 버튼

## 캐릭터 추가하는 법

GitHub에서 `data.js`를 열고 연필 아이콘(Edit)을 눌러서 `CHARACTERS` 안에 아래 덩어리를 복사해 붙이면 끝이에요.

```js
{
  id: "c",                    // 겹치지 않는 영어/숫자
  name: "C",
  subtitle: "한 줄 소개",
  image: "images/c.jpg",
  info: [["나이", "00"], ["직업", "—"]],   // 상태 항목 (없어도 돼요)
  intro: `간단한 소개`,                     // 없어도 돼요
  prompt: `프롬프트`
},
```

## 참고

- 수정은 저장소 주인(본인 계정)만 할 수 있어요. 방문자는 보고 복사만 가능해요.
- 공개 저장소라서 프롬프트는 링크를 아는 사람이 저장소 코드에서도 볼 수 있어요.
- 입장 화면은 브라우저를 켠 뒤 처음 한 번만 나와요. 다시 보려면 새 탭/시크릿 창으로 열면 돼요.
- 사진이 없어도 금색 이니셜 칸으로 대신 보여서 먼저 써보셔도 괜찮아요.
